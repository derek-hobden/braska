# Review Staged Files Button

## Priority: Medium

## Description
Add a button near the staged changes section that invokes the code reviewer expert on all currently staged files. This provides a quick way to get a code review before committing, without having to manually select files or switch contexts.

## Tasks
- Add a "Review" button next to the staged changes header in the right panel
- On click, collect the list of all currently staged files
- Invoke the code reviewer expert, passing the staged files as input
- Display the review results in an appropriate view (e.g., a new tab or panel)
