# Open Tickets in Content Tabs with Quick-Action Button

## Priority: Medium

## Description
When selecting a ticket from the right-hand panel, the ticket should open as a new tab in the content section rather than just being selected in the list. The corresponding ticket in the right panel should be highlighted to indicate it's the one currently viewed in the active tab.

Additionally, each ticket in the right-hand panel list should have a small icon/button that kicks off a session to work on that ticket directly. This allows the user to start tackling a ticket straight from the list without needing to open it first — useful when the title alone makes the ticket clear.

## Tasks
- Open tickets as new tabs in the content area when clicked in the right panel
- Highlight the ticket in the right panel that corresponds to the currently active tab
- Add a "work on this ticket" button/icon to each ticket entry in the right panel list
- Clicking the work button should kick off a session to tackle that ticket directly
