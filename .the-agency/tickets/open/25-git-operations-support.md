# Git Operations Support

## Priority: High

## Description
The application currently has limited git functionality. It needs full support for common git operations so users can manage their repositories without leaving the app. This includes committing changes, fetching from remotes, pulling updates, and other standard git workflows.

## Tasks
- Add ability to commit staged changes with a commit message
- Add git fetch support to retrieve remote updates
- Add git pull support to integrate remote changes
- Add git push support to publish local commits
- Add git branch management (create, switch, delete branches)
- Add git stash support (stash, pop, list)
- Add git diff viewing for uncommitted changes
- Add git log viewing for commit history
- Add UI controls for triggering these operations
