# Create Ticket Button in Tickets Panel

## Priority: Medium

## Description
Add a button to the tickets panel in the right-hand panel that allows creating a new ticket directly from there. The button should open a new tab with the Ticketmaster expert, providing a quick way to file tickets without manually navigating to the expert.

## Tasks
- Add a "New Ticket" button to the tickets panel in the right-hand panel
- Wire the button to open a new tab with the Ticketmaster expert
